# Research notes: growth.activation_rescue

## Why this workflow

Tin's current public README describes organic growth, content, cold outreach, product QA, creative work, project context, and related workflows. Its roadmap explicitly calls out lifecycle marketing as an area for future expansion.

The workflow therefore targets a narrow lifecycle job: turning an observed signup-to-activation leak into one testable rescue campaign.

## Existing Tin coverage checked

- Current public repository README: the listed workflow areas include organic growth, content, cold outreach, product QA, creative work and project context.
- Open pull requests checked on 2026-09-24 include signup-source collection, awesome-list discovery, audience prospector, directory submissions, sunset-tool rescue, error-page SEO, churn-reason digest, competitor switcher battlecard, sales-objection mining, landing-page conversion/messaging audit, coding-agent discovery, community demand radar, and competitor-review mining.
- None of the checked open PR titles is an activation-leak-to-rescue-campaign workflow.

This is a gap assessment, not a claim that no private/unindexed work exists.

## Outside inspiration

Amplitude's activation guidance treats activation as a measurable key action and recommends funnel/cohort analysis to understand where new users drop off.

Customer.io's onboarding documentation recommends segment-triggered campaigns focused on a specific behavioral goal, and its lifecycle material describes activation campaigns triggered when a user signs up but does not complete the core action within a defined window.

The workflow combines those ideas into a Tin-specific process: diagnose one leak from supplied evidence first, then produce one bounded campaign brief rather than generic lifecycle advice.
